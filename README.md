2026-10-31에 제작한 정적 페이지입니다. `index.html`, `styles.css`, `assets/`를 같은 디렉터리에서 제공하면 동작합니다.

게시 주소: https://lllilill.github.io/jeju-siruwon-landing/
GitHub 저장소: https://github.com/lllilill/jeju-siruwon-landing

## 게시 전 확인

- 상품 가격·구성·재고·운영시간·배송 조건을 사업자와 확인합니다.
- 생성형 연출 이미지 5개를 실제 상품·매장·제조 사진으로 교체할지 결정합니다. 현재 페이지는 상단과 이미지 설명에 연출 사실을 명시했습니다.
- 스마트스토어 `https://smartstore.naver.com/siruwon`과 지도 검색 링크가 현행 채널인지 확인합니다.
- 광고 성과 추적이 필요하면 승인된 분석 도구와 캠페인별 UTM을 추가합니다.

## GitHub Pages

새 공개 저장소의 기본 브랜치 루트에 이 디렉터리의 파일을 올린 뒤, 저장소 Settings > Pages에서 `Deploy from a branch`와 `main / (root)`를 선택합니다. 게시 URL은 GitHub가 표시한 값을 최종 확인합니다.
